## 📱 Design & Engineering Standards
* **Hallmark Floor**: Clean `:root` tokens, zero invented metrics, `overflow-x: clip`, instant `:focus-visible`.
* **Emil Kowalski Micro-Physics**: Tactile `:active { transform: scale(0.97); }` press feedback, `cubic-bezier(0.16, 1, 0.3, 1)` easing.
* **Taste Skill**: Clean, confident typography, equal margins, signature developer card.
* **Impeccable Surface Theming**: Themed `::selection`, custom scrollbar, WCAG contrast compliant ($\ge 4.5:1$).
